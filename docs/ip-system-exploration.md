# WhatMint IP 体系探索记录

本文记录 WhatMint 当前阶段对 IP 体系、交互哲学和产品方向的阶段性判断。它是产品探索文档，不等同于已上线应用清单；新 IP 进入开发前仍需按 `docs/product-design-principles.md` 填写立项卡，并按新核心范式接入。

## 核心发现

WhatMint 的 IP 不是先创造角色，再邀请用户进入一个幻想世界。

WhatMint 的 IP 从现实生活里的一个具体动作和一个容易被忽略的小瞬间出发，让实体成为情绪入口。

核心公式：

```text
现实动作 x 情绪需求 x 轻交互 x 魔法瞬间
```

WhatMint 不是创造一个逃离现实的幻想世界，而是让现实世界多一点点微童话。

它不负责解决人生的大问题，只负责让那些原本会被匆匆略过的小瞬间，值得被轻轻认真对待。

## 统一 IP 哲学

WhatMint IP 不是角色库，而是一套现实动作的情绪化表达系统。

每个 IP 都要先回答：

- 它守住的是哪个小瞬间？
- 它依附在哪个现实物？
- 用户为什么会在那个瞬间触碰它？
- 它的核心动作是否足够简单？
- 它是否能带来明确的情绪变化？
- 它是否允许用户重新解读和二创？

一个好的 WhatMint IP 不需要解释复杂世界观。用户只要看到物、动作和回应，就能理解它为什么存在。

## 当前 IP 矩阵

### 纸巾小狗

核心场景：

人在难过、疲惫、感冒、需要安慰或想表达关心的时候。

核心动作：

递。

提供情绪：

被接住、被理解。

产品哲学：

纸巾本身是普通物品，但它可以被重新解释为一个表达关心的动作。

纸巾小狗不是宠物，而是一种温柔行为的具象化。它不负责解决难过，只是在难过被藏起来时，递出一点点可以被接住的温柔。

可重新解读空间：

纸巾小狗可以送给感冒的朋友，也可以放在厕所、书桌、床边或礼物里。场景可以变化，但核心动作仍然是递出一点温柔。

### 喝彩便签

核心场景：

学习、工作、开始任务、完成任务，或充实地过完一天。

核心动作：

划掉。

提供情绪：

被看见、被肯定。

产品哲学：

任务工具通常关注“你有没有完成”。喝彩便签关注“你的努力值得被庆祝”。

它不是效率工具，而是把微小完成变成一个仪式。它只有一个核心动作：为你放礼炮。

设定方向：

喝彩便签是放在桌面的“小庆祝者”。你写下任务，它为一天的开始放礼炮；你完成任务并长按划掉，它为你放礼炮；你没有做完任务，它也可以为你喝彩，因为你充实地过完了这一天。

人格方向：

偏傻雕、可爱、有反差感。它像一个永远愿意为你鼓掌的小伙伴。

可重新解读空间：

用户可以认真用它降低开始任务的心理压力，也可以把任务写成“去上厕所”“打开文档”“喝一口水”。当它一本正经地为这些小事放礼炮时，反差感会自然形成二创空间。

### 装装

核心场景：

准备、整理、状态切换。

例如：

- 出门旅行。
- 收拾背包。
- 婴儿车准备。
- 工作前准备。

核心动作：

装进去。

提供情绪：

安心、准备感。

产品哲学：

装装不是提醒用户“别忘东西”，而是陪用户一起收拾。

它把“我是不是还没准备好”的焦虑，转化成“我正在一点点准备好”的过程感。

交互方向：

碰一下进入整理状态。用户确认物品后，物品以动画进入包里。最后所有东西准备完成，装装给出一个轻轻的出发确认。

人格方向：

认真、可爱、可靠。像一个奇妙但靠谱的小生物，关心每一样东西是否找到了自己的位置。

### 桌面秘境

核心定位：

桌面上的一个小地方。

核心动作：

进入。

产品哲学：

桌面秘境不是 AR 内容消费，也不是小游戏。实体贴纸先装饰现实空间，AR 只是让这个装饰拥有生命。

它的核心不是“我可以切换很多场景”，而是“这里是我的地方”。

建议机制：

一个贴纸绑定一个秘境。

例如：

- 雪山补给站。
- 森林补给站。
- 湖泊补给站。
- 海边补给站。

用户购买时选择自己的秘境，不建议把多个场景做成自由切换播放器。否则它会从“我的地方”退化成“App 里的场景库”。

变化来源：

秘境不是养成游戏，而是会轻轻变化的空间。变化可以来自时间、季节、小事件和生态内 IP 偶遇。

例如：

- 某天森林里长出蘑菇。
- 某天装装路过留下箱子。
- 某天纸巾小狗在湖边休息。

IP 不是桌面秘境的主体，世界观只是补充。桌面秘境更像用户可停留的微空间入口。

## 统一设计原则

### 1. 从动作出发，而不是从功能出发

不要先问“我要做一个什么工具”，而要先问“人在这个瞬间会做什么动作”。

动作越简单，越容易成为用户记住的魔法瞬间。

### 2. 实体不是载体，而是仪式入口

NFC 的价值不是打开页面，而是让一个普通物品拥有一个魔法瞬间。

如果没有实体也一样成立，它就不是 WhatMint 想做的现实世界 UI。

### 3. 轻交互承载深情绪

避免复杂流程、复杂世界观和复杂 AI。

核心是：

```text
一个简单动作 -> 一个情绪变化
```

### 4. 不制造虚假世界，而是在现实中创造一点温柔

WhatMint 的目标不是让用户逃离现实，而是让现实中那些被忽略的小瞬间被重新珍惜。

微童话感不是幼稚幻想，而是现实被轻轻点亮的一瞬间。

## 阶段性判断

当前成立度较高的方向：

- 纸巾小狗：情绪入口，接住难过和关心。
- 喝彩便签：高频成长场景，让努力被看见。
- 桌面秘境：空间入口，让桌面拥有一个可停留的小地方。
- 装装：行为陪伴，让准备与出发更安心。

这几个方向初步形成：

```text
身体动作 -> 现实行为 -> 情绪空间 -> 内心状态
```

下一阶段重点不是继续增加 IP，而是验证哪些现实动作最值得被 WhatMint 铸造成魔法瞬间。
