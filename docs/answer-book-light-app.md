# WhatMint 轻应用：答案之书

## 气质定位

答案之书不是占卜，不是心理咨询，也不是万能 AI。

它是一枚可以被触碰的现实回应入口：用户带着一个问题碰一下，得到一句清醒、克制、有一点反差感的回应。

它的气质应该是：

- 正念作为方法，不作为说教。
- 答案像从现实里冒出来，不像从课程里摘出来。
- 温柔但不甜，清醒但不冷。
- 有一点黑色幽默，但不伤人。
- 不替用户做决定，只把用户带回当下。
- 不预测未来，只指出此刻可以看见的东西。
- 允许荒诞，但最后落回身体、呼吸、行动和关系。

一句话：

碰一下，答案不会拯救你，但会把你从脑内会议里请出来。

## 内容边界

- 不做医疗、法律、金融、心理诊断建议。
- 不使用绝对化命令，例如“必须”“一定”“马上离开”。
- 不做恐吓式、宿命式、诅咒式表达。
- 不把“正念”写成课程笔记。
- 不要求用户输入私密问题，问题留在用户心里。

## 内容结构

每组答案包含：

- 主句：一眼看到的答案。
- 回应：一段短解释。
- 小动作：一个可以马上做的正念或行动。
- 标签：用于抽卡、筛选和后续个性化。

## 可抽象的平台能力

从答案之书可以抽象出一类新的 WhatMint 平台能力：即时回应型轻应用。

和耳机小姐的连续故事空间相比，它不强调持续叙事，而强调当下触发、随机抽取、情绪标签和再次抽取。

后续平台能力可以包括：

- 牌组管理
- 答案卡管理
- 情绪标签
- 抽取规则
- 当日去重
- 触碰记录
- 分享卡生成
- 品牌或空间定制牌组

## 参考气质来源

- Netflix 剧集《Murder Mindfully / Achtsam Morden》：正念语言和黑色喜剧现实之间的反差感。
