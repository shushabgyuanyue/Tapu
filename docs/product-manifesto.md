# WhatMint 产品宣言与设计语言

## 核心信念

WhatMint 不是 NFC 工具，不是普通内容平台，也不是把网页贴到现实物体上的二维码替代品。

WhatMint 要做的是：

把现实世界变成可以被触碰的界面。

用户碰一下一个贴纸、摆件、礼物、作品或日用品，不是在打开一个链接，而是在让这个物体补上它原本想表达却无法表达的部分。它可以是安慰、祝愿、答案、纪念、清单、AR 场景或一段只在关键时刻出现的留言。

WhatMint 不是创造一个幻想世界。WhatMint 是让现实世界多一点点微童话。

它不负责解决人生的大问题，只是让那些原本会被匆匆略过的小瞬间，值得被轻轻认真对待。

## 现实世界 UI

WhatMint 的基本单位不是普通应用，而是：

```text
IP + 应用 + 实体入口 + 场景
```

一个 IP 必须回答：它属于哪个现实物？用户为什么在这个生活瞬间触碰它？触碰之后，它替这个物表达了什么？

例如：

- 纸巾小狗：在需要安慰或表达关心时，触碰后出现小狗递纸巾的数字表达。
- 桌面秘境：在学习、办公或短暂休息时，触碰桌面贴纸后让一个 AR 场景出现在桌面上。
- 未来的正念回应、清单、纪念或传信方向，也必须先证明自己的物件、行为和意义，再按新核心范式接入。

因此 WhatMint 不是给物增加功能，而是给物补上表达。

## Mint Space 叙事

Mint Space 是用户拥有后的个人入口。

它不是购买后的附属功能，也不是资产仓库，而是用户查看、管理和继续触发自己拥有的现实入口的地方。

用户购买的不是一个商品，而是邀请一个能服务某个生活场景的存在进入自己的 Mint Space：

- 纸巾小狗不是玩偶，而是安慰场景的入口。
- 桌面秘境不是装饰，而是桌面 AR 场景的入口。

因此，对客表达应尽量使用：

- 邀请新的存在。
- 进入我的 Mint Space。
- 我的伙伴。
- 赋予物体新的表达。

谨慎使用：

- 商品货架。
- 资产仓库。
- 展品。
- 任务、等级、抽卡、数值成长。

购买逻辑应该从“我要买一个东西”转化为：

> 我的生活里有一个瞬间，值得被一个现实入口轻轻点亮。

## 风格调性

WhatMint 的风格是：

有灵气，有个性，歌颂美好，同时成熟克制，兼具商业性。

这不是简单的可爱、治愈、神秘或科技感。

它是一种现实物体被轻轻点亮后的气质：

- 有灵气，但不幼稚。
- 有个性，但不吵闹。
- 歌颂美好，但不廉价正能量。
- 成熟克制，但不冷漠。
- 具备商业性，但不破坏体验。

## 有灵气

灵气来自物体开始拥有一点自己的语气、立场和生活。

小狗会承载安慰。  
一枚桌面贴纸会让一个普通桌面忽然出现一片小小秘境。

灵气不是堆光效、堆梦幻、装神秘。

它更像现实中的一个物，在被触碰的瞬间，向用户轻轻偏了一下头。

## 有个性

WhatMint 前台应该是 IP 化的。

用户不需要先理解 token、路由、权限、内容容器或应用运行时。用户只需要先理解：

- 这是纸巾小狗。
- 这是桌面秘境。
- 这是某个会留下故事的作品。

每个轻应用都应该像一个小 IP，拥有名字、语气、物性、触碰动作和可被讲述的场景。

OS 能力隐藏在后台。前台让用户先喜欢一个具体的物。

## 歌颂美好

WhatMint 歌颂美好，但不制造廉价正能量。

它歌颂的是：

- 普通生活里的小光。
- 关系里没说出口、但可以被物轻轻表达的在意。
- 物体和人之间的记忆。
- 情绪被安放的一瞬间。
- 日常里很小但真实的仪式感。

WhatMint 允许难过、疲惫、犹豫、沉默存在。

美好不是消灭阴影，而是承认现实有重量，同时给它留一盏小灯。

## 成熟克制

成熟克制是 WhatMint 和普通情绪产品的分界线。

我们避免：

- 过度可爱。
- 过度温柔。
- 过度解释。
- 过度情绪化。
- 过度神秘。
- 过度功能教育。

我们坚持：

- 文案短一点。
- 情绪留白多一点。
- 动效慢一点。
- 交互少一点。
- 页面不急着证明自己。
- 不把用户当成需要被哄的小孩。

最好的触碰体验应该是：

用户碰一下，页面安静地打开，给出一段刚刚好的回应，然后把感受还给用户自己。

## 兼具商业性

WhatMint 必须好卖，但不俗。

商业性来自现实物体天然的流通能力：

- 贴纸成本低，适合规模化。
- 摆件和 IP 适合溢价。
- 礼物场景天然有付费意愿。
- 品牌包装可以接 B 端合作。
- 咖啡店、书店、展览、酒店、校园和企业礼品都能成为触碰场景。
- 每个物都可能成为会员、内容、复购、活动或服务入口。

但商业转化不应该破坏体验。

用户应该先觉得“这个东西有意思”，再觉得“我想送人”或“这个品牌挺会”。购买、复购和合作应该从物体数字空间自然长出来，而不是被弹窗硬塞进去。

## 设计语言原则

### 1. 现实物是主角

页面服务于物体，不抢物体的戏。

轻应用需要让用户明确感到：这是某个物的空间，不是一个泛网页。

### 2. 触碰后直接进入体验

减少解释、注册、弹窗、教程和多余路径。

先让用户感受到物的回应，再邀请用户拥有、保存、登录或继续探索。

### 3. 每个应用都要有自己的语气

统一不等于同一套情绪。

纸巾小狗、桌面秘境以及后续重新接入的新应用可以完全不同，但都要遵守 WhatMint 的克制、灵气和留白。

### 4. 内容比功能更靠前

用户碰一下后首先看到的应该是回应、故事、声音、画面或情绪，而不是功能说明。

功能藏在后面，体验站在前面。

### 5. 轻交互，不加负担

轻应用的交互应该少而准。

优先使用：

- 碰一下。
- 再问一次。
- 复制。
- 保存。
- 绑定。
- 进入 Mint Space。

谨慎使用复杂表单、长流程和多层配置。

### 6. 商业入口要像体验的一部分

购买、复购、品牌合作、活动领取和会员入口，都应该和物体的情绪空间自然相连。

不要让商业入口像外来的广告。

## 判断准则

当我们设计一个新轻应用或 OS 能力时，可以用这几个问题校准：

- 它是否让一个现实物体变得更有生命？
- 它是否有一个用户能记住的名字和场景？
- 它是否守住了一个容易被忽略的小瞬间？
- 它是否通过一个简单动作带来明确情绪变化？
- 它是否先提供体验，而不是先解释系统？
- 它是否保持克制，没有把情绪讲满？
- 它是否能自然长出商业入口，而不破坏触碰体验？
- 它是否把复杂的路由、权限和 OS 能力藏在后台？

如果答案大多是肯定的，它就更接近 WhatMint。

## 一句话

碰一下，让物体以自己的方式回应你。

这句话不是功能描述，而是 WhatMint 后续产品、内容和设计语言的共同方向。
